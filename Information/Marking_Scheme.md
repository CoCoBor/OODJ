# 1.0 Coursework Title

## APU Automotive Service Centre (APU – ASC)

---

# 2.0 Coursework Overview

The assignment is to design and implement a system to support the **APU Automotive Service Centre (APU – ASC)**.

There are four types of end users interacting with the system:

1. Managers
2. Counter Staff
3. Technicians
4. Customers

The application should include the following features:

- Login access
- User registration
- Set prices
- Create new appointments
- Assign new appointments
- Check and update assigned appointments
- Collect payments and generate receipts
- Access service and payment histories
- Provide feedback and comments
- Generate analysed reports

In addition, a supporting document is required to reflect the design of the implementation codes and the implementation details that utilize Object-Oriented Programming (OOP) concepts.

---

# 3.0 Objectives of This Coursework

Develop the practical ability to:

- Describe an Object-Oriented system
- Justify design decisions
- Implement an Object-Oriented system

# 5.0 Coursework Description

As an Object-Oriented Programming student, you are required to:

- Identify relationships among entities
- Develop a user-friendly application
- Fulfill the required features listed in Section 2.0

The application should support four types of access rights:

- Managers
- Counter Staff
- Technicians
- Customers

The table below shows the functionalities accessible by each user role upon login.

---

# 6.0 Functional Requirements

| Role | Functionalities |
|---|---|
| **Managers** | - Create/Read/Update/Delete managers, counter staff, and technicians<br>- Set prices for normal service and major service<br>- View all feedback and comments<br>- Analyze reports |
| **Counter Staff** | - Edit personal profile<br>- Create/Read/Update/Delete customers<br>- Create and assign new appointments (Normal Service: 1 hour, Major Service: 3 hours) to available technicians<br>- Collect payments and generate receipts |
| **Technicians** | - Edit personal profile<br>- Check comments and details of assigned appointments<br>- Update assigned appointments to `"Completed"`<br>- Provide feedback for assigned appointments |
| **Customers** | - Edit personal profile<br>- Access individual service and payment histories<br>- Access feedback for appointments<br>- Provide comments for counter staff and technicians involved in appointments |
